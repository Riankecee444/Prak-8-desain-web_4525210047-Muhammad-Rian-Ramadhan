
# Ringkasan Pengerjaan

Project ini merupakan form registrasi event yang dibuat menggunakan HTML, CSS, dan PHP. HTML digunakan untuk membuat struktur formulir yang terdiri dari input nama, email, nomor telepon, radio button jenis tiket, select kategori peserta, textarea alasan mengikuti event, upload bukti identitas, dan checkbox persetujuan.

CSS digunakan untuk mengatur tampilan formulir agar lebih menarik, rapi, dan responsif ketika dibuka melalui desktop maupun perangkat mobile. PHP digunakan untuk memproses data serta melakukan validasi di sisi server sebelum pendaftaran diterima.

Selama pengerjaan, beberapa kesalahan yang mungkin terjadi adalah nama tidak diisi, format email tidak sesuai, nomor telepon salah, kategori atau jenis tiket belum dipilih, serta file yang diunggah tidak sesuai ketentuan. Untuk mengatasi masalah tersebut, dibuat aturan validasi menggunakan PHP sehingga data yang tidak sesuai akan ditolak oleh sistem.

Validasi server sangat penting karena pemeriksaan dari browser saja tidak cukup untuk menjamin kebenaran data. PHP juga memeriksa ukuran dan tipe file sebelum menyimpannya ke folder uploads.

Dengan adanya form ini, proses pendaftaran event menjadi lebih terstruktur dan mudah digunakan.

## Pembagian Peran
Tugas dikerjakan secara individu, mulai dari pembuatan struktur HTML, desain CSS, pemrograman PHP, hingga pengujian.
