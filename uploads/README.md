
# Form Registrasi Event

## Deskripsi
Form registrasi event dibuat menggunakan HTML, CSS, dan PHP.

## Teknologi
- HTML
- CSS
- PHP

## Fitur
- Input nama lengkap
- Input email
- Input nomor telepon
- Radio button jenis tiket
- Select kategori peserta
- Textarea alasan mengikuti event
- Upload bukti identitas
- Checkbox persetujuan
- Validasi server
- Tampilan responsive

## Cara Menjalankan
1. Install XAMPP.
2. Simpan folder project di htdocs.
3. Aktifkan Apache.
4. Buka browser.
5. Masukkan alamat:

http://localhost/form_registrasi_event/

## Validasi
Semua data diperiksa kembali menggunakan PHP
sebelum pendaftaran diproses.
